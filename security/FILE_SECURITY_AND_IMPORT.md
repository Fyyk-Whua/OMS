# 文件安全与统一导入中心设计

更新时间：2026-07-12

## 处理链路

上传文件 → 隔离区 → 类型与内容安全检测 → 病毒扫描 → 完整性摘要 → 解析 → 数据校验 → 结果预览 → 用户确认 → 正式入库。

## 文件安全规则

- 不信任文件名和扩展名。
- 校验扩展名、MIME 和 Magic Number。
- 默认拒绝可执行文件和带宏 Excel。
- 检查外部链接和危险公式。
- 保存 SHA-256 摘要。
- 所有文件必须先进入隔离区。
- 未通过安全验证的文件不得进入业务处理。
- 文件访问必须经过租户、用户和业务权限校验。

## 数据校验

按以下层次执行：

1. 模板结构校验。
2. 字段类型、长度、必填和格式校验。
3. 业务规则和引用数据校验。
4. 重复数据和幂等校验。

每条错误至少包含行号、字段、原值、错误类型和原因。

## 正式导入

校验阶段不得写入业务表。存在失败记录时，默认不导入。用户确认后才可以选择仅导入成功部分；也可以返回修改源文件后重新上传。

正式导入必须使用事务、生成导入任务结果并记录操作审计。

## 分页

默认 100 条/页；下拉值为 100、200、300、500、1000、2000、5000；允许用户输入其他正整数。非法数字、小数和非正数必须分别提示并由前后端同时校验。
