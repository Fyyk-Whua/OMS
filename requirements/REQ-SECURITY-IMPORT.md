# 文件安全与数据导入需求

更新时间：2026-07-12

## 文件安全

- `REQ-SECURITY-005` CONFIRMED：所有文件上传必须经过统一文件安全网关。

统一检查包括：

- 文件大小限制
- 扩展名、MIME 和 Magic Number 一致性
- 病毒扫描
- SHA-256 完整性摘要
- 宏文件默认拒绝
- Excel 外部链接和危险公式检查
- 隔离区扫描
- 文件权限与生命周期
- 安全日志

业务模块不得直接读取未经安全验证的上传文件。

## 统一导入中心

- `REQ-IMPORT-001` CONFIRMED：所有模板导入使用统一 Import Center。
- `REQ-IMPORT-002` CONFIRMED：文件结构、字段类型、长度、必填项和业务规则分层校验。
- `REQ-IMPORT-003` CONFIRMED：失败记录必须返回行号、字段、原值、错误类型和可理解的失败原因。
- `REQ-IMPORT-004` CONFIRMED：导入结果必须使用服务端分页展示。

## 导入确认规则

1. 校验阶段不得写入正式业务表。
2. 存在失败记录时，系统不得自动导入成功部分。
3. 点击确认时必须让用户明确选择：
   - 仅导入校验成功的数据；
   - 返回修改文件后重新导入。
4. 默认不执行部分导入。
5. 所有正式导入必须生成任务结果和审计记录。

## 导入结果分页

- 默认每页 100 条。
- 下拉选项：100、200、300、500、1000、2000、5000。
- 允许手工输入正整数，例如 6000。
- 非数字提示“请输入有效数字”。
- 小数提示“请输入整数”。
- 0 或负数提示“分页数量必须大于 0”。
- 前端和后端都必须校验。

## 错误文件导出

支持导出原始数据和错误原因列，便于用户修正后重新导入。
