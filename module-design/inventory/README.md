# 库存中心设计

更新时间：2026-07-12

## 1. 模式

### OMS 独立库存模式

支持仓库、库区、货位、库存余额、库存流水、Excel 初始化、调整单、简单移动和轻量盘点。不支持波次、PDA、拣货路径、复核和仓储优化。

### ERP 库存模式

ERP 为库存权威。OMS 保存库存快照并维护未被 ERP 确认的软占用。ERP 确认后，库存责任由 OMS 转交 ERP，并刷新 ERP 快照。

## 2. 可售库存

统一由 Sellable Inventory Service 计算。基础顺序：

1. 校验租户、企业、店铺、库存组织、仓库和 SKU。
2. 过滤冻结、损坏、退货待检和禁售库存。
3. 扣除有效订单占用、履约锁定、调拨锁定和安全库存。
4. 应用共享库存池、渠道额度和活动额度。
5. 单独计算预售额度。
6. 组合商品按组成 SKU 最小可组合数量换算。

现货和预售必须分别返回、分别展示、分别占用。

## 3. 预售策略

预售属于运营策略。策略包含开始时间、结束时间、额度、预计到货时间、状态和到货监测规则。超期、人工取消或到货监测命中都会停止新增预售，但不会取消既有预售订单。

到货监测采用指定时间窗口内库存净增加量与用户阈值比较。触发后既有预售订单按审核通过时间 FIFO 进入转现货队列。

## 4. 库存流水

库存余额和库存流水分离。每次变化记录前后数量、变化类型、业务对象、操作人和时间。完成流水不可直接修改或删除，错误通过冲销修正。

库存流水界面筛选：

- 日期：默认上个月 1 日至当前日期，可调整。
- 企业、店铺、库存组织：为空时查询授权范围内全部数据。
- 后端必须进行权限交集校验。
- 服务端分页。
- 长期保留，不做业务归档。

## 5. 占用生命周期

占用记录包含类型、数量、状态、过期时间、幂等键、责任方和失败原因。OMS 独立模式在一个事务内完成校验、占用、流水和余额更新。

ERP 模式采用双阶段：OMS 软占用 → ERP 正式确认。网络超时进入 UNKNOWN，不得立即释放，通过状态查询补偿确认。

组合商品使用 `ReservationGroupId`，全部真实 SKU 占用成功才算成功。

## 6. 补偿与异常

库存补偿任务处理 ERP 成功但 OMS 未确认、释放失败、重复扣减和状态不一致。任务必须幂等，超过重试次数转人工处理。

第一阶段 OMS 独立库存不允许负库存。
